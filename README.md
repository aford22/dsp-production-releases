# DSP Production

A production-chain calculator for Dyson Sphere Program, as a Windows desktop app.

**Download:** get the latest installer (`DSP Production_<version>_x64-setup.exe`) from the [Releases page](https://github.com/aford22/dsp-production-releases/releases/latest).

Installed copies check this repository for new versions and offer to update themselves.

Windows may show a SmartScreen warning because the installer is not yet code-signed: choose "More info", then "Run anyway".
